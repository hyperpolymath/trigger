=== The honest nuance you must not lose

* *"Fails here" is not "never worked".* Each failure below is measured at the
  toolchain versions in the anchor. Two of them look like code written for an
  older toolchain:
** The Zig `telegram` module calls `@ptrCast` and `@alignCast` with two
   arguments. Current Zig takes one.
** Every Idris2 module imports `Control.Monad.Effect`, which is the Idris 1
   Effects library and does not ship with Idris 2.
* Some failures do not depend on the version:
** The Agda modules declare `--safe` and also contain postulates (8 in
   `Trigger/API.agda`, 5 in `Trigger/Epistemic.agda`). Agda rejects that
   combination in every version.
** Four Zig modules fail at the *parser*, for example `@null,` in
   `crypto/crypto.zig:121`.
* *SPARK proofs were not checked, rather than found failing.* `gnatprove` is
  not installed here, and the project file does not process, so the SPARK
  layer is untested at this anchor.
* *The Ada tests were not runnable.* The test target goes through the same
  project file that fails to process.

== Reproduce it yourself

From a clone checked out at the anchor commit:

[source,bash]
----
git checkout 0755f3b99b0ee103b554aa1c3d5fd515dcca301b
just build                                     # Justfile parse error at 223
gprbuild -P trigger.gpr -XLIBRARY_TYPE=static  # rc=5, project file rejected
for d in crypto discord social_media twitter telegram; do
  (cd ffi/zig/$d && for f in *.zig; do zig build-lib -fno-emit-bin "$f"; done)
done
(cd ffi/idris2 && for f in *.idr; do idris2 --check "$f"; done)  # look for "Error:"
(cd proofs/agda && agda Trigger/API.agda && agda Trigger/Epistemic.agda)
----

Agda needs agda-stdlib. Point `AGDA_DIR` at a directory whose `libraries` file
names the stdlib's `.agda-lib` and whose `defaults` file says
`standard-library`.
